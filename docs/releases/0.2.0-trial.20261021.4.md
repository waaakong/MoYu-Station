# 0.2.0-trial.20261021.4 — 原生安装启动保护候选

状态：代码修复和本地回归，尚未构建、验收、发布或部署。本记录不代表生产已开启推送。

## 已实现

- 本地保存／备份失败明确归为保存不可用；磁盘不足保留专用错误，不再误报网络失败。
- manifest-signed 使用确认启动的 NSIS 适配器：保留上游下载、清单、摘要和签名验证以及安装参数生成，操作系统发出实际进程启动事件后才退出应用，不以预先取得 PID 代替启动确认。
- 原生启动失败不退出当前应用，交由既有错误处理撤销安装意图并解除写入冻结；拒绝未确认的 shell／提权回退。
- 仅适用于现有按用户安装的完整安装包。需要管理员权限的包或系统拒绝执行时停止自动安装，提示检查权限／手动安装；不绕过 UAC、不修改系统信任库。trusted 模式保留原 Authenticode 验证路径。
