# 0.2.0-trial.20261025.2

今日摸鱼改为片刻放松页面累计，假努力指数按秒级区间实时预估，并将学习卡片的系统日期弹窗替换为统一深色日历。

摸鱼不再等于在线减专注。普通在线、暂停专注和浏览社区均不计入新摸鱼；进入片刻放松仍暂停专注。跨端重叠按区间并集去重，专注优先，日期采用北京时间。指数公式保持（专注 + 摸鱼 × 2）÷ 在线，非百分比，零分母显示暂无。旧日期保留旧口径并标注，不能反推缺失的娱乐停留。

新增 V17 仅添加可空的区间分类与娱乐时长字段，不回填历史、不删除记录。回退仅处理应用和配置，不能用旧库覆盖上线后的新记录。

已完成本地类型检查、457 项前端单测、后端单元／迁移检查及 8 项真实 MySQL 账本用例。定向浏览器验证日历四尺寸、键盘、日期竞态、PNG 导出及实时计时去重；源码冻结后的 CI 与生产部署结果另行记录。

本版仍为无受信任 Authenticode 签名的试用安装包，使用既有 Ed25519 签名清单。生产新版安装／自动升级和两台真实客户端长期累计尚未验证；不宣称其他用户已经升级。原有视觉基线及硬件观察限制保留。
