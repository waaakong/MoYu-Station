# 0.2.0-trial.20261027.1

本版包含无编号6×6拼图、中文反馈状态、Ctrl+Alt全局轮盘、平滑上滑的桌面歌词，以及酷狗会员音源授权和分段续播修复。轮盘可从最小化状态呼出；桌面歌词支持外观、锁定与托盘找回，开启时带回主窗口所在屏幕，不显示底部播放状态文字。

安全整改包括可终止的音乐元数据解析子进程、外部链接校验收窄、相关npm依赖更新、Tomcat补丁及可信反代来源修正。没有扩大音乐平台账号权限或媒体主机白名单。网页仍不接入平台音乐；客户端仍先登录墨屿，再登录对应平台。

实验 `.103` 已经用户实体键盘核对声音面板导航及最小化恢复；`.104` 已实播原版《晴天》4:29，包含用户暂停续播并自动下一首；`.105` 已由用户确认当前屏幕可见、实际歌词同步及平滑上滑。`.106` 已核对移除底部状态文字且保留原实验账号。503项桌面单测通过，歌词真实renderer浏览器回归通过。这些结果不替代本版正式安装包和生产升级验收。

发布步骤：固定本次main提交，连续两轮完整CI及正式Windows制品核对；服务器备份及隔离恢复验证后，部署网页／后端及下载包，保持V17和既有策略、成员记录；新版本先导入DRAFT，再由管理员本人复验开启WaaaKong试点。正式客户端通过一次点击下载、校验、备份、覆盖安装和重启，实际核对通过后才逐级扩大灰度。回退应用和配置，不用旧数据库覆盖新增记录。

剩余限制：无受信任Authenticode签名，Windows管理员／安全提示由用户确认；部分媒体／专注轮盘命令、快捷键冲突、多DPI／全屏／多屏边界、歌词鼠标穿透及完整安全审计仍未全部验收。历史视觉基线、其他账号实机回执及长期压力测试保留未验。Spring Boot旧维护基线未迁移，不宣称全部漏洞已消除。生产推送、本人升级及正式制品哈希仍待后续证据补齐。
