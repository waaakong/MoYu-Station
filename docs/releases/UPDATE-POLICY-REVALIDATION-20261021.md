# 更新策略持续复核修复（尚未发布）

## 实际问题与边界

隔离 Windows 沙盒在真实下载完成、草稿忙碌等待期间，后端已提交 PAUSED 策略，但客户端在 30 秒观察窗口内仍保留安装意图。旧应用未退出或被覆盖。完整故障矩阵因此未通过，生产推送仍关闭。

源码检查确认：后端只在正向发布时广播提示；客户端按发布 ID 去重，忽略同一发布的后续策略；普通自动检查间隔无法满足活动安装意图的持续复核。

## 修复

- 所有已提交策略变更发送独立、携带 policyVersion 的变更提示；保留正向旧通知兼容性。回滚不发送提示。提示不包含凭据，不代替实际权限检查。
- 客户端按事件、通道、发布及策略版本识别提示；更新连接恢复后立即复核，覆盖断线期间错过的变更。
- 用户已授权的下载／忙碌等待／倒计时期间，每 15 秒通过原认证接口复核。关闭自动发现不关闭这项安全复核；取消、退出、失效、安装阶段结束时停止。
- 频繁活动状态上报不得不断推迟复核；重复检查不恢复旧授权，不解除草稿等待或重置倒计时。
- 保留安装前双重复核、清单和文件校验、身份绑定以及保存失败保护。

## 验证与剩余门禁

本地桌面单测 452 项通过；桌面类型、构建、敏感信息与身份／平台边界检查通过。新增回归包含同版本策略修订、重连补查、关闭自动发现后仍复核、频繁忙碌上报不推迟复核、取消后停止复核，以及推送前鉴权。

当前修改尚未由新安装包在沙盒中验证，不复用旧制品或旧 CI 作为本次通过证据。真实 MySQL 事务提交／回滚通知回归另列，普通后端单测不代替该集成验收。

仍需新源码快照两次 Linux 浏览器 CI 零重试通过、新引导及目标制品、沙盒故障续验、真实正常退出与重启、隔离卷磁盘耗尽、实际忙碌 UI 及生产本人试点。旧候选和失败证据保持不变；不改写已有标签或制品。
