# 原生预览复验修正

## 范围与依据

实验 .20261030.101 已由用户确认：实体轮盘快捷键录制及最小化呼出正常；歌词显示、同步、上滑及颜色正常。用户要求移除手动保存，并报告静音不同步、流沙缺失、设置窗口叠加。当前正式候选尚未发布，暂停该候选后续发布准备。

## 交互

1. 客户端设置修改即生效并自动持久化，移除保存按钮及离页保存确认。连续拖动合并写入，串行提交；快捷键仅在完整录制结束后提交，不提交录制中间值。注册冲突保留旧有效快捷键并显示具体错误；保存失败显示重试，不谎称已保存。异步回执不能覆盖较新的编辑。
2. 轮盘音乐静音使用与播放器相同的音乐总线。静音时音量条及数值显示有效音量 0%，保留静音前设置；取消静音恢复原值，拖动音量条解除静音。白噪音总线不受影响。
3. 舞台恢复已批准预览的持续缓慢流沙／流体运动。氛围运动不依赖音频能量是否可读；真实频谱、声波及节拍增强仍仅采用真实分析数据，缺失信号不伪造。暂停保留缓慢氛围，减少动态、隐藏窗口及离页停止动画，关闭背景不绘制。保留帧率与分辨率限制。
4. 客户端设置沿用个人页单层内容结构，去掉内部重复的“墨屿设置”大边框／窗口壳；桌面歌词与快捷轮盘作为页内分类。听歌舞台的设置入口导航到该设置页并提供返回舞台，不再叠加独立客户端设置对话框。色板／下拉仍为控件级浮层，保留键盘、Esc 与焦点恢复。

## 验证与发布

检查自动保存连改、乱序回执、冲突与失败恢复；轮盘及各音乐音量控件保持一致且不影响白噪音；有声、无可读信号、暂停及减少动态下的背景；个人页与舞台往返无双层窗口。重新构建实验包并复验上述差异，再生成新正式候选，核对下载页、日志、公私库及更新制品。未发布的候选不作为已上线版本，既有正式客户端及策略维持原样。
