# 听歌舞台、桌面歌词与快捷轮盘改版规格

日期：2026-10-29。状态：视觉方案与书面规格均已由用户确认；详细实施计划已编写，尚未修改产品实现或部署。

## 1. 范围与依据

- 用户已确认动态预览 v17：三种舞台布局、六种歌词样式、四种背景；透明桌面歌词、双行色板和八向渐隐轮盘。
- 产品基线为公开仓库 main 的 76c2f26。实施前重新核对 HEAD、工作区和相关后续提交，保留无关改动。
- 参考 Folia 的舞台分层与流动氛围、Mineradio 的能量驱动视觉、lolPing 的方向选择反馈；独立设计实现，不移植其源码或游戏素材。
- 网易云桌面歌词参考来自本机实际可见界面：透明底、描边文字及小型锁定控件。播放中的逐字效果未因本次外观观察而视为实测。
- 本轮还包括 SSE 断连日志修复、客户端设置迁移、删除独立全局媒体快捷键、修复轮盘快捷键保存和注册。
- 不增加平台音乐权限，不将平台音乐接入网页；不新增云端 AI、HiFi、自动混音、插件市场或安全审计以外的新功能。

## 2. 听歌舞台

### 2.1 布局、歌词与背景

三种布局为“封面＋歌词”“沉浸歌词”“纯视觉”。六种歌词样式为“平滑滚动”“居中聚焦”“阶梯错落”“超大文字”“对话气泡”“文字分镜”。四种背景为“封面流光”“光带频谱”“流体声波”“封面星云”，另有“关闭”。三组选择独立保存；纯视觉隐藏歌词样式控件，返回歌词布局时恢复上次选择。

- 封面流光：取封面配色并平滑混合；灰阶封面使用受控冷暖补色；换封面不闪白、不无限叠加图层。
- 光带频谱：连续轮廓、平滑峰值、辉光、峰值标记与弱倒影；背景不得影响歌词可读性。
- 流体声波：横向开放式多层波带，错位起伏、冷暖柔光与沿波面流动的微粒，不恢复规则闭合圆环。
- 封面星云：可辨识的封面粒子成像、有限纵深与环绕星尘；无封面有明确回退。
- 文字分镜仅使用歌词与稳定种子生成有限模板；不用网络模型推断歌曲主题。

产品中的频谱、波形和响应幅度使用已有播放器的真实分析数据。无法读取真实数据时，显示静态氛围及“当前音源不支持音频响应”；不使用预览模拟信号充当真实频谱。暂停后冻结响应，切歌和 seek 校正时钟，恢复播放不补播积压动画。

### 2.2 同一播放器和时间轴

舞台、声音页、全局播放器及桌面歌词共享当前曲目、队列、播放状态和时间。不得创建第二播放器或因样式切换重复建立音频图。音乐与白噪音继续独立调节。

以播放器实际位置为基准；暂停、seek、切歌、恢复及歌词偏移变更均产生校正。真实逐字时间存在才逐字高亮；只有逐行时间时按行切换，不按字数估算后宣称逐字同步。无歌曲、无歌词、歌词加载失败、无封面和音频失败分别展示，歌词失败不阻断音频。

## 3. 客户端设置与颜色

入口为“我的 → 客户端设置”，分类为“桌面歌词”“快捷轮盘”。声音页提供跳转入口，不重复展示完整设置表单。网页不提供无法工作的桌面设置入口。

桌面歌词设置保留显示、锁定、找回位置、字体、字号、单／双行、平滑上滑和歌词不透明度。滑条均显示当前数值。颜色位于文字外观内：

1. “歌词高亮”在上，“歌词原色”紧接在下，样式一致。
2. 每行 10 个预设色：苔绿、月白、雾蓝、暖杏、淡紫、玫瑰、薄荷、海盐、琥珀、银灰；末尾为彩色自定义按钮。
3. 点击彩色按钮展开统一样式调色盘，包含二维饱和度／明度区域、色相条、可键盘操作的饱和度和明度滑条、HEX 输入、颜色预览与关闭／完成。
4. 两种颜色独立设置；原色用于未高亮文字与下一句。当前选中色有选中环，色值可读。
5. HEX 仅接受六位 RGB，可规范化大小写；不接收任意 CSS 字符串。无效输入保留上次有效颜色并显示原因；完成或关闭时丢弃无效草稿，不让隐藏弹层持续阻塞设置保存。
6. 调色盘修改即时预览，完成关闭调色盘；“保存设置”持久化。Esc 或点外部关闭弹层并恢复触发按钮焦点，不关闭整页设置。外观即时预览与已保存状态区分明确。
7. 删除独立“自定义高亮色／歌词原色”设置块，不恢复原生系统颜色弹窗作为主要界面。

## 4. 桌面歌词窗口

- 默认无厚重卡片、无常驻标题或播放中／暂停文字；透明窗口背景，以清晰描边和轻阴影保证歌词在浅色及深色桌面可读。
- 未操作时只保留歌词；悬停或键盘进入时显示紧凑图标工具栏：拖动、上一首、播放／暂停、下一首、锁定、设置和关闭。图标有可访问名称与提示。
- 锁定后不得误拖动；仅显示必要的解锁入口，托盘与客户端设置始终可解锁、找回位置。
- 保留已确认的平滑上滑换句；只有邻近行参与动画。seek、切歌及恢复时直接定位，不长距离追赶。
- 单行只显示当前句；双行显示当前与下一句。长句在可用宽度内自适应；达到最小字号后允许受控滚动，减少动态时采用静态截断并可查看完整句，不溢出屏幕。
- 不透明度作用于歌词内容，工具栏保持可操作。字体、原色与高亮色同时作用于窗口和设置预览。
- 保留原生透明、置顶、锁定／鼠标穿透及 IPC 权限边界；浏览器预览不替代这些原生行为验收。
- 窗口位置按工作区边界约束；显示器移除、分辨率／DPI 改变及找回操作均确保窗口可见，不重置全部用户设置。

## 5. 全局快捷轮盘

### 5.1 外观与操作

- 八向、每向 45°；环形底座有深浅径向层次和细分隔线，弱化实心圆盘与粗外框。
- 所有八个方向（包含四个斜角）均有向外渐隐的柔光；选中时对应方向提亮并延伸，图标约放大 1.18 倍。
- 外环主要显示图标，不常驻长文字；中心显示当前操作图标和名称，空闲中心提示取消。较长名称换行，不溢出。
- 保留墨屿青绿、浅金配色和自主图标；正式全局窗口周围透明，不增加全屏模糊遮罩。
- 展开约 120ms，选中反馈约 80–100ms；减少动态使用静态选中反馈。动画不延迟命令执行。
- 默认 Ctrl＋Alt，按住呼出、移向操作、释放组合键中任一键执行一次；中心、Esc、右键取消。按键重复和迟到释放不得重复执行。
- 原生窗口以呼出点为中心，适配屏幕边缘和 DPI，命中区域与视觉方向一致。最小化主窗口时可用；全屏应用开关沿用用户设置，默认关闭。
- 页面预览中的点击执行仅用于视觉确认，不能替代全局按住／释放验收。

### 5.2 自定义快捷键与命令

保留八个可配置位置及现有命令能力。命令状态取自同一播放器和专注状态；不可用项说明原因，取消时不改变播放／专注状态。

录制显示当前组合键，Esc 取消恢复原值。保存时校验支持的按键、系统保留组合及注册结果；失败提示原因并保留原配置与已工作的注册，不能先注销旧键后留下无快捷键状态。仅更改歌词外观不重新注册轮盘。设置保存、系统注册和界面回执保持一致，快速保存不让旧回执覆盖新设置。

修复启动时无条件把 Control＋Alt＋Space 改为 Control＋Alt 的逻辑：旧默认键只在有版本标记的一次性迁移中处理；无法区分用户自定义时保留值。重启后恢复真实已保存的自定义组合，不重置为默认。

删除独立全局媒体快捷键设置和 MediaPlayPause／上一首／下一首注册；保留播放器、轮盘和歌词窗口的播放按钮。旧配置读取时兼容但不再注册这些独立快捷键。

## 6. SSE 断连日志

区分正常离页、客户端取消、网络断开与真实服务错误。发送失败或 emitter 完成后幂等释放订阅、心跳任务和连接记录，不继续发送。

已识别的客户端断开不输出服务错误堆栈；真实业务异常仍记录。SSE 响应已提交后，不让通用异常处理器再写 JSON 错误体引发二次异常。不用全局吞异常或关闭错误日志解决问题。重连沿用现有鉴权、退避和通知边界，不扩大跨页面连接范围。

## 7. 实现边界

- StageHost 管理布局与可见性；LyricStyleRegistry 和 BackgroundRegistry 管理样式、首帧就绪及销毁。
- SharedLyricsSession 统一歌词读取、偏移与缓存；舞台、声音页和桌面歌词消费同一会话。账号切换与曲目变化隔离迟到结果，不残留上一账号数据。
- StageClock 从播放器状态生成只读时钟；可见且播放中才做视觉插值，收到校正事件立即更新。
- StagePreferences／客户端设置契约采用版本化校验和兼容迁移；未知枚举回退，颜色、字号、透明度等有边界。保持应用身份、队列、曲库、用户设置和存档。
- GSAP 用于面板、下拉框、调色盘、轮盘和有界歌词过渡；Canvas／既有分析器负责波形、频谱和粒子。不要逐帧创建 tween 或更新整棵 Vue 树。
- 清理动画、RAF、监听、观察器和 GPU 资源；隐藏舞台停止相应视觉渲染，但可见桌面歌词仍更新。窗口之间仅传所需歌词与状态，不额外暴露凭据或文件路径。
- 画质档提供 24／40／60fps 上限和自动回退，不承诺所有设备达到上限。预热邻近歌词，缓存文字测量和封面处理结果，限制并发图层与缓存容量。
- 优先复用 AppSelect、现有设置存储和 IPC 校验，不引入整套新渲染框架或任意代码／命令配置能力。

| 歌词会话 | 逐行／逐字、空／错歌词、偏移、暂停、seek、快切歌、账号变化和迟到请求；多视图时间一致 |

| 焦点 | 下拉框／调色盘键盘操作、Tab 边界、Esc 仅关闭最上层、焦点返回，不被父弹层抢焦点 |

浏览器定向尺寸为 1440×900、1280×720、1080×640、390×844；检查截图、控制台、键盘与减少动态。类型、相关单测、后端测试、构建、边界和敏感信息检查按改动执行。真实媒体、全局快捷键、透明原生窗口、多 DPI 未实测时明确保留，不用预览或模拟断言宣称通过。

## 9. 实施顺序与交付

实施计划分为：SSE 独立修复；共享歌词与舞台；设置／色板／快捷键持久化；原生轮盘与歌词；集成和实机验收。每阶段产出可检查代码与证据，避免把全部预览脚本直接搬入产品。

书面规格审阅后再编写详细实施计划。当前不执行生产部署、客户端覆盖、公开 Release 或推送策略变更。正式发布仍同步客户端制品、下载页及校验值、更新日志、公私库源码与发布记录，并区分已交付／已验证／剩余限制。不重写已发布制品，不用旧用户数据覆盖新增记录。
