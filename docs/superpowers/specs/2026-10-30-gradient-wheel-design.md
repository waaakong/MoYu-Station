# 渐变透明快捷轮盘

## 已确认的外观

用户选择 lolPing 式深色扇区，并于 2026-10-30 确认动态预览 v3 的渐变程度。以该预览为实现依据：内圈深灰，向外逐渐透明；选中高亮、八个方向的分隔线同步淡出，不保留实心底盘或硬外圆边。采用预览默认灰金配色、青绿色中心；不新增配色切换设置。图标自主绘制，不引入游戏素材或音效。

## 几何与交互

- 原生透明窗口保持 480×480；八个方向顺时针排列，命令顺序仍读取用户现有设置。
- 扇区内半径 66、外半径 224；图标中心半径 116，尺寸 30。中心圆半径 65，外侧细环至 69。
- 中心显示当前操作及“松开执行”；未选中显示“移向操作／中心取消”。图标选中放大至 1.16 倍。
- 中心取消判定从旧版半径 82 调整为 66，与批准的预览中心一致。移出外边缘仍保持原有方向选择，不新增外缘取消行为。
- 保留已验证的快捷键录制、全局呼出、最小化呼出、松键执行及 Esc／右键取消。渲染层不接收或执行自由命令，不新增动作 IPC。

## 动效与边界

沿用批准预览的 GSAP 动效：呼出约 120ms、0.88 倍缩放至原尺寸；方向切换约 100ms，后来的选择覆盖正在播放的过渡。每次原生呼出拥有独立序号，中心移动不能重复触发入场动画。减少动态时立即显示；隐藏和销毁时停止过渡，无空闲持续动画循环。

GSAP 本地打包并保留上游许可，不通过网络加载脚本，不放宽轮盘 CSP。仅接受八个已知且不重复的命令；显示名称使用固定映射，拒绝无效帧，迟到帧不能触发原生命令。

## 验收与发布条件

1. 单测核对八向及中心边界、取消和既有执行规则；类型与边界检查通过。
2. 实际渲染器检查八个方向、连续换向、重复呼出、减少动态及透明外缘，并与批准预览截图对照。
3. 新实验包沿用原实验数据，实体键盘复验呼出、松键执行、最小化恢复及当前屏幕显示；确认实际透明窗口效果。
4. 完成后才继续正式更新。正式发布同时固定源码、版本和安装包校验值，同步下载页、更新日志、公私 GitHub 仓库；未完成原生验证不得宣称正式交付。保留当前正式安装及生产策略，直到对应更新步骤执行。
