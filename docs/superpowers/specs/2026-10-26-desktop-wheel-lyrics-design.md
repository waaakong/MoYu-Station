# 全局快捷轮盘与桌面歌词设计

日期：2026-10-26。状态：交互预览已确认，书面规格待复核。基线：main c6af9c4。作者：WaaaKong。

## 已确认范围

用户选择 B：全局按住快捷键呼出，拖向操作，松开执行；墨屿最小化时仍可用。默认八项：播放／暂停、上一首、下一首、音乐静音、专注开始／暂停、声音面板、桌面歌词、返回空间。允许自定义顺序和快捷键，保留原媒体快捷键。

桌面歌词参考网易云音乐的使用体验，使用墨屿自己的视觉与资源。用户确认透明悬浮、悬停工具栏、锁定穿透、外观设置，以及动态预览的向上换句效果。自编演示歌词和模拟时间不作为真实歌词能力验收。

本规格只负责桌面控制与歌词；拼图、反馈中文、安全整改及酷狗 VIP 各自验收后纳入同一版本。不修改网页版的平台音乐边界。

## 轮盘

建议默认组合 Ctrl+Alt+Space，可在设置中更改；不以单独 Alt/Ctrl 截获日常操作。注册冲突明确提示并保留旧配置，不偷偷改键。按下打开，移动选择，释放触发一次。中央死区、Esc、右键、焦点／桌面切换及输入异常均取消，不执行悬而未决的命令。长按自动重复不重复打开或执行。

采用小型 Windows 原生输入辅助进程处理按下／释放及拖动边界，Electron 绘制独立透明轮盘。输入处理不等待渲染主线程；只监听和处理明确配置的组合，不记录、持久化或上传其他键盘内容。进程默认普通用户权限，不安装服务、不请求管理员权限。安全桌面／锁屏不显示；遇到更高权限应用无法正常工作时取消，不提权抢占。全屏应用默认暂停轮盘，可由用户在设置中显式开启。

辅助进程使用固定打包路径和有限消息协议；校验消息长度、枚举、会话和序号，拒绝重复／迟到消息。辅助进程退出、通道断开或轮盘未就绪则取消当前操作并恢复正常输入。不得接收任意可执行路径、脚本、URL 或命令行。发布时纳入制品哈希和第三方许可检查。

主进程维护唯一轮盘操作会话。窗口只接受来自自身主 frame 的有限操作，不借用主窗口的通用 IPC 权限。命令通过既有播放器／专注服务执行，遵守登录、内容权限、忙碌状态以及离开空间暂停专注规则；不能因为轮盘呼出而改变计时。无可播放内容、无主窗口或播放器失联时给出可理解提示。

轮盘以鼠标所在屏幕的工作区定位，边缘夹紧，支持多屏不同 DPI、负坐标和拔屏。无需抢走底层应用焦点；退出时恢复原窗口使用。保留设置页按钮和现有快捷键作为替代入口。

## 桌面歌词

扩展现有 DesktopMusic／独立歌词窗口，不创建第二套播放器。共享曲目身份、账号作用域、播放位置、播放／暂停状态及歌词偏移。主窗口最小化时继续同步；关闭歌词后停止无用发布和动画；正常退出不留下悬浮进程。

实际窗口透明、置顶，不抢输入焦点。解锁时可以拖动，悬停／键盘聚焦显示播放、上一首、下一首、锁定、外观、关闭工具栏。锁定后工具栏收起并鼠标穿透；托盘和主窗口设置始终提供解锁／重置位置入口。轮盘“桌面歌词”仅切换显示，不改变播放。

设置包括字号 22–48、可读的高亮色、单／双行、位置及锁定状态。对颜色及数值采用精确 schema。保存设置时兼容旧 desktop music 配置，不能因新增字段重置已有快捷键。位置按工作区夹紧，拔屏后回到可见区域。触屏及键盘用户也能从主窗口完成所有设置。

当前句使用较大字号，下一句略小且弱化。正常相邻换句在 280ms 内向上接续：旧当前句上移淡出，旧下一句移至当前位置并放大，新下一句从下方进入。只动画 transform／opacity；逐字填充使用裁剪。不得推移工具栏或整个窗口。拖动进度、切歌、账号变化直接定位并取消旧动画，不排队播放跨过的句子。连续更新可打断，旧歌词异步回包不得覆盖新曲目。减少动态模式取消位移与缩放，保留清晰状态切换。

逐字高亮必须来自歌词源的真实逐字起止时间；普通 LRC 采用整句同步，不按字符均分推算。解析格式增加前先检查平台真实返回结构、大小和时间范围。不能支持的格式明确降级为整句。纯音乐、暂无歌词、读取失败、会话失效、尚未开始、已暂停分别显示适当状态；失败不停止音乐，切歌立即清除上一首文字。所有歌词仅按文本渲染，不接受 HTML、脚本或网络资源。

## 安全和生命周期

歌词与轮盘都使用 contextIsolation、sandbox、禁用 Node、拒绝导航／弹窗／权限请求及独立受限 preload。歌词 frame 限制文本长度、行数／词数、时间范围和发送速率；高频 UI 更新不得使主进程无界排队。登录退出／切号立即取消旧曲目读取；既有更新下载／保存／重启授权规则保持不变。

## 验收

单元与契约测试覆盖输入状态转换、重复／迟到回包、取消、辅助进程崩溃、设置回滚、命令拒绝、歌词排序／异常时间／普通 LRC 回退和切歌竞态。预览使用模拟时间，实机必须使用真实播放器时钟。

Windows 10 测试机通过 UU 观察原生桌面，验证最小化呼出、快捷键冲突、Esc／中央取消、全屏和多屏 DPI、锁定穿透与解锁、拔屏找回、音量／播放／专注状态一致，以及歌词暂停／跳转／跨曲目同步。截图尺寸延续 1440×900、1280×720、1080×640、390×844 的适用界面检查。没有逐字源或真实多屏硬件时单列未验证，不能用模拟代替。
