# 下一版实现与验收记录（生产发布前）

日期：2026-10-26。状态：本地实现与自动化验证，尚未生产部署；Windows原生及酷狗真实会话待复验。提交身份 WaaaKong。

## 实现

- 拼图新增6×6，保留3×3、4×4存档，移除视觉编号和正确块号的无障碍提示。
- 反馈状态显示中文；原始状态码、本人复验、冲突版本校验保持。
- 原生Windows轮盘辅助进程、透明独立轮盘、八项有限命令、设置及顺序交换；固定路径打包解包执行，不接受任意脚本。心跳中断、中心、Esc、右键、焦点变化取消。
- 歌词透明浮窗、悬停工具栏、锁定／托盘解锁、字号／颜色／单双行、280ms上滑。Enhanced LRC真实时间解析，普通LRC整句；跳转取消动画、暂停立即同步。
- 音乐元数据移至可终止子进程，限制并发／时间／堆／返回大小，裁剪环境；外部URL拒绝凭据、非标准端口和超长输入。
- 已只读核对生产反代使用追加X-Forwarded-For；后端改读可信回环代理覆盖的X-Real-IP，单入口配置改覆盖来源头。仅改源码，没有修改生产配置。
- Tomcat 9.0.83→9.0.123，维持javax.servlet兼容线；未进行Spring大版本迁移。
- 酷狗：付费目录标记不再代替当前账号授权；用户明确选择已知曲目时读取新鲜授权，非试听、有权限且有效安全媒体地址才允许。自动跨源回退规则未扩大。
