# 原生预览修正实施清单

已批准设计：../specs/2026-10-30-native-preview-corrections-design.md。

1. 自动设置提交：保留草稿隔离，新增串行合并提交控制，避免旧回执覆盖新编辑；移除保存动作，完整录制后提交快捷键，失败保留重试。验证连续编辑、录制取消、失败重试及离页。
2. 静音：轮盘调用音乐总线；所有音乐音量视图显示有效音量，拖动解除静音，保留恢复值。验证播放器同步且不影响环境音。
3. 动态背景：独立推进氛围时钟，真实频谱仍读分析器；隐藏、离页、减少动态及背景关闭停止循环。验证无声、暂停及停止绘制。
4. 单层设置：移除个人页嵌套窗口壳；舞台设置入口导航个人客户端设置，受限返回地址恢复舞台。验证键盘及返回行为。
5. 运行相关单测、类型及浏览器定向回归，修复后冻结源码，构建新实验版进行差异复验；通过后按既有发布门禁重新准备正式制品。旧候选不发布。
