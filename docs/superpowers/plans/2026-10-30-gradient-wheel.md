# 渐变轮盘接入记录

依据用户确认的渐变透明预览及再次要求同步客户端，按既有设计实施。

1. 将预览的渐变、66/224半径、116半径图标及中心样式接入原生HTML/CSS/SVG渲染器，不添加自由输入或新的执行IPC。
2. 本地打包GSAP，保留许可头和CSP；仅在新呼出序号时播放入场，移动仅更新高亮，隐藏／销毁停止过渡。独立显示序号跨输入服务重启递增。
3. 命中规则中心区域与可见中心一致，保留外侧方向选择和松键执行。用实际渲染器截图验证渐变透明与有限帧；检查单位测试、类型、边界及打包资源。
4. 固定源码生成独立实验 .110，保留实验用户数据，先核对版本及资源，再正常启动原生复验。正式安装和推送仍留待原生验收及完整发布门禁，不以预览或单测冒充上线。
