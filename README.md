# 墨屿自习室 · MoYu Station

给今天留一间，会呼吸的自习室。

墨屿将窗景、专注计时、本地音乐、环境音与片刻放松放在同一个空间里。Windows 桌面端提供完整的本机能力，网页版无需安装即可使用。

[进入网页版](https://8.163.29.26/scene) · [下载与更新日志](https://8.163.29.26/download) · [GitHub Releases](https://github.com/waaakong/MoYu-Station/releases) · [开发者文档](docs/development/README.md)

## 可以做什么

- **选择窗景**：内置场景与七个光影时段，支持私人自定义场景；云端功能需登录。
- **保持专注**：设置时长、暂停和继续，查看学习记录、日历与历史日期卡片。
- **调整声音**：播放自己的本地曲库、歌词、歌单和公开电台；音乐与环境音可分别调节音量。
- **片刻放松**：使用呼吸训练、电子木鱼及益智小游戏，支持本机存档。
- **连接同伴**：登录后使用聊天、动态、互动通知与个人空间。
- **保留自己的节奏**：桌面端保存曲库、队列、设置和游戏进度，切换页面不重建播放会话。

进入“片刻放松”页面的累计时间计为今日摸鱼；离开空间页面会暂停专注，返回后由你继续。今日在线、摸鱼和假努力指数按秒实时估算，云端与本机记录合并去重；历史记录保留原统计口径，不补造数据。

## 下载与安装

目前提供 **Windows x64** 客户端。macOS、Linux 和 Windows ARM 专用安装包尚未提供。

1. 前往[下载页](https://8.163.29.26/download)，以页面实际显示的版本、大小和 SHA-256 为准。
2. 下载页提供 GitHub Releases 公开安装包入口；服务器备用下载仍需墨屿账号登录。只有真实发布的 Release 才可下载，以下载页当前状态为准。
3. 首次安装运行安装包并选择目录；已有客户端请先正常退出（包括托盘），再安装到原目录，无需先卸载或删除用户数据。
4. 安装后可进入本地空间；注册、同步与社区功能取决于所连接服务的账号和邀请码策略。

当前试用安装包**尚无受信任的 Authenticode 签名**。请核对来源和校验值；遇到安全软件告警时停止安装，不要关闭系统防护或导入不明证书。

## 更新方式

当前已安装版本采用“检查版本 → 提示 → 前往下载页 → 手动安装”。新的自动更新代码已完成本地验证，但生产自动下载安装尚未启用。

后续启用的更新流程为：登录后检查授权版本，由你确认下载，可查看进度、取消和重试；安装前保存本机数据并复核版本、权限和撤回状态。专注、播放和未提交草稿不会被静默打断。需要先安装一次支持新流程的引导版。

公开 GitHub Release 中的安装包可被任何人下载，不再受墨屿下载登录限制；账号、私人媒体与社区权限仍由服务端控制。

## 平台音乐与数据

- 平台音乐仅面向客户端；在允许的试用构建中，先登录墨屿，再登录对应音乐平台。
- 这不是网易云音乐、QQ 音乐或酷狗音乐的官方客户端。接口、账号权益和平台风控可能影响使用；不提供会员、付费、版权、地区或 DRM 绕过。
- 源码默认构建不自动开启实验平台能力。平台凭据仅在本机受限存储，不提交至本项目后端或 GitHub。
- 本地歌曲文件与本机队列不作为音乐内容上传。云端聊天、动态、上传图片和同步记录由所连接服务按权限处理。
- 不要在 Issue 中上传账号凭据、私人图片、用户数据库、会话、完整日志或签名私钥。
